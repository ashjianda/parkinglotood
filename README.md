# Design a Parking Lot 

Design a Parking Lot with parking spots that can hold motorcycles, cars, and buses. Motorcycles can park in any spot. Cars can park in car or bus spots. Buses can park in bus spots. Vehicles should be able to park and unpark. One vehicle can only park in 1 spot at a time. Duplicate license plates are not allowed.

My Java solution is included in this repo.
